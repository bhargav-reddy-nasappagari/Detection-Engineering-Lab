1. Session ID definition

we derive one logical session

SESSION_ID = S1 (auid=1000, tty=pts4, window: 15:42–15:45)

We are deliberately collapsing:

* auditd EXECVE logs
* auth logs
* process tree

into one correlated session object

2. Unified Session Reconstruction Table

Legend for “Stage”

INIT → session / shell setup
DISCOVERY → system introspection (whoami, hostname, uname)
ENUM_USER → users/groups/passwd enumeration
ENUM_SYSTEM → services, processes, sockets
PRIV_PROBE → sudo, unix_chkpwd, privilege checks
DEF_AWARENESS → log inspection / audit querying
